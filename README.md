# PokePoke Discord Bot (Version 3.0.0)

A Discord uitlity tools for user in voice channel for poking afk people in voice chanel


## Features
- poke system
- slash command
- app menu
- set the time to mute headphone
- set the time to mute microphone

## Tech Stack

| Technology    | Version   |
| ---------------| -----------|
| Ptyhon        | >= 3.11   |
| flask         | >= 3.0.0  |
| discord.py    | >= 2.3.0  |
| pytz          | >= 2024.1 |
| python-dotenv | >= 1.0.0  |

## Installation

### Clone respository

```bash
git clone https://github.com/TAHPAPANGKORN/PokeBotDiscord.git
cd PokeBotDiscord
```

### Install dependency
```bash
pip install -e .
```

### Create your .env
```bash
cp .env.example .env
```

### Run bot
```bash
python src/main.py
```
