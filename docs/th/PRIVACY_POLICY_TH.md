# นโยบายความเป็นส่วนตัว (PokePoke)

**อัปเดตล่าสุด:** 27 พฤษภาคม 2026

ความเป็นส่วนตัวของคุณเป็นสิ่งสำคัญยิ่งสำหรับเรา นโยบายความเป็นส่วนตัวนี้ชี้แจงถึงวิธีการที่ **PokePoke** ("บอท") เข้าถึง ประมวลผล และปกป้องข้อมูลส่วนบุคคลของผู้ใช้ การเพิ่มบอทนี้เข้าไปยังเซิร์ฟเวอร์ Discord ของคุณ หรือการมีปฏิสัมพันธ์ใด ๆ กับบอท ถือว่าคุณยินยอมตามแนวปฏิบัติเกี่ยวกับข้อมูลที่ระบุในนโยบายนี้

### 1. ข้อมูลที่เราประมวลผล (การจัดเก็บข้อมูล)
PokePoke จะเข้าถึงและประมวลผลเฉพาะข้อมูลที่จำเป็นทางเทคนิคอย่างยิ่ง เพื่อใช้ในการทำงานของฟีเจอร์ต่าง ๆ ของบอท (เช่น การย้ายช่องเสียง และการจัดการสถานะเสียงชั่วคราว):
*   **Discord User ID และ ชื่อผู้ใช้ (Usernames):** เพื่อระบุตัวตนของผู้ใช้ที่เป็นผู้สั่งการ หรือผู้ที่เป็นเป้าหมายในการย้ายห้อง (`/poke`) รวมถึงการตั้งค่าระงับการเข้าถึงชั่วคราว
*   **Guild (Server) ID และ Channel ID:** เพื่อระบุเซิร์ฟเวอร์และช่องเสียงเป้าหมายที่บอทต้องเข้าไปดำเนินการย้ายสมาชิกและส่งข้อความตอบกลับ
*   **สถานะช่องเสียง (Voice States):** เพื่อตรวจสอบว่าผู้ใช้ยังอยู่ในช่องเสียงหรือไม่ อยู่ในช่องเสียงใด และเพื่อตรวจสอบสถานะการเปิด/ปิดไมค์หรือหูฟัง

### 2. นโยบายไม่มีการบันทึกเสียง (NO VOICE OR AUDIO RECORDING)
*   **ข้อตกลงสำคัญที่สุด:** แม้ว่า PokePoke จะต้องได้รับสิทธิ์ (Permissions) ที่เกี่ยวข้องกับช่องเสียง เช่น การย้ายสมาชิกและการเปิด/ปิดเสียงสมาชิก **แต่ตัวบอทไม่มีนโยบายการฟัง ดักฟัง สตรีม บันทึก หรือจัดเก็บข้อมูลเสียง (Audio/Voice/Conversation Data) ใด ๆ ของผู้ใช้ทั้งสิ้น** การสนทนาทั้งหมดของคุณในช่องเสียงจะยังคงเป็นส่วนตัวอย่างสมบูรณ์และบอทไม่เคยรับรู้ข้อมูลดังกล่าว

### 3. การจัดเก็บข้อมูลและการรักษาความปลอดภัย
*   **ไม่มีการเก็บข้อมูลถาวร (No Persistent Databases):** PokePoke ไม่มีระบบฐานข้อมูลหรือการบันทึกข้อมูลส่วนบุคคลของผู้ใช้ลงบนฮาร์ดไดรฟ์หรือเซิร์ฟเวอร์ภายนอกแบบถาวร
*   **ประมวลผลบนหน่วยความจำชั่วคราว (RAM):** ข้อมูลที่ใช้ในการประมวลผลทั้งหมดจะถูกเก็บไว้ในหน่วยความจำชั่วคราว (RAM) และจะถูกลบออกทันทีเมื่อการประมวลผลคำสั่งนั้นสิ้นสุดลง หรือเมื่อบอททำการรีสตาร์ท
*   **บันทึกการทำงานเพื่อวินิจฉัย (Debug Logs):** คอนโซลของผู้โฮสต์บอทอาจมีการแสดงข้อผิดพลาด (เช่น ปัญหา API Rate-limit หรือข้อผิดพลาดในโค้ด) เพื่อใช้ในการแก้ไขปัญหา บันทึกเหล่านี้จะไม่มีการบันทึกรายละเอียดข้อมูลส่วนตัวหรือเนื้อหาข้อความของผู้ใช้ และจะถูกลบออกเป็นระยะ

### 4. การเผยแพร่ข้อมูลและการแบ่งปันแก่บุคคลภายนอก
*   **ไม่มีการขายหรือแบ่งปันข้อมูล:** เราไม่มีการขาย แลกเปลี่ยน ให้เช่า หรือแบ่งปันข้อมูลส่วนบุคคลของผู้ใช้หรือเซิร์ฟเวอร์ให้แก่บุคคลภายนอกใด ๆ ทั้งสิ้น
*   **ระบบของ Discord:** PokePoke ทำงานร่วมกับระบบอย่างเป็นทางการของ Discord ผ่านทาง Discord API การใช้งานบอทนี้จึงถือว่าคุณยอมรับข้อตกลงและนโยบายความเป็นส่วนตัวของ Discord ด้วยเช่นกัน โดยสามารถอ่านรายละเอียดได้ที่ [นโยบายความเป็นส่วนตัวของ Discord](https://discord.com/privacy)

### 5. สิทธิ์ของเจ้าของข้อมูลส่วนบุคคลและการขอข้อมูลคืน/ลบข้อมูล
ภายใต้กฎหมายคุ้มครองข้อมูลส่วนบุคคล (เช่น PDPA หรือ GDPR) ผู้ใช้งานมีสิทธิ์ขอตรวจสอบหรือขอให้ลบข้อมูลส่วนตัวของตนได้
*   เนื่องจาก PokePoke **ไม่มีการจัดเก็บข้อมูลส่วนตัวใด ๆ ไว้ในฐานข้อมูลถาวร** จึงไม่มีข้อมูลส่วนบุคคลหลงเหลืออยู่ให้ลบในระบบฐานข้อมูล
*   หากคุณมีข้อสงสัยหรือต้องการสอบถามเพิ่มเติมเกี่ยวกับการประมวลผลข้อมูลส่วนตัวชั่วคราว สามารถติดต่อผู้พัฒนาได้โดยตรงตามช่องทางด้านล่าง

### 6. นโยบายเกี่ยวกับผู้เยาว์
บอทนี้ไม่ได้ออกแบบมาและไม่มีการตั้งใจจัดเก็บข้อมูลของเด็กที่มีอายุต่ำกว่า 13 ปี หากคุณพบว่ามีข้อมูลของเด็กอายุต่ำกว่า 13 ปีหลุดรอดเข้ามาในระบบบันทึกชั่วคราวของเรา โปรดติดต่อเราทันทีเพื่อที่เราจะได้ดำเนินการลบข้อมูลดังกล่าวโดยเร็วที่สุด

### 7. การเปลี่ยนแปลงนโยบายความเป็นส่วนตัว
ผู้พัฒนาขอสงวนสิทธิ์ในการแก้ไขอัปเดตนโยบายความเป็นส่วนตัวนี้ได้ทุกเมื่อ โดยจะระบุวันที่แก้ไขล่าสุดไว้ด้านบน การใช้งานบอทต่อไปหลังจากมีการเปลี่ยนแปลงจะถือว่าคุณยินยอมรับเงื่อนไขใหม่นี้
